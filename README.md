# 👑 HERCULES | هِـرْكِـلِـيز
## المنظومة الرقمية الشاملة الفاخرة (The Obsidian & Neon Violet Ecosystem)

تم بناء منصة **HERCULES (هِـرْكِـلِـيز)** بأعلى معايير الفخامة البرمجية والتصميمية بثيم **حجر الأوبسيديان الأسود والنيون البنفسجي المتوهج (Obsidian & Glowing Neon Violet)**، مع دعم كامل للغة العربية (RTL First)، وتكامل الأركان الأربعة المطلوبة، وقاعدة بيانات مستمرة مع لوحة تحكم كاملة للمدير، ونظام تسجيل مستخدمين متكامل واستوديو أدوات ذكاء اصطناعي تفاعلي يعمل داخل المنصة دون استهلاك كريديتس الخادم.

---

### 🌟 الأركان الأربعة للمنظومة

#### 1. 🛒 المتجر الرقمي (Hercules Market)
- **بيع وشراء المنتجات الرقمية الفاخرة**:
  - قوالب مواقع وواجهات UI (Next.js 14, React, Tailwind, Figma UI Kits).
  - ملفات Photoshop وPremiere وAfter Effects (MOGRTs, LUTs سينمائية، انتقالات 4K، Mockups).
  - إضافات وبرمجيات وأدوات (WordPress SEO Automation, Scripts).
  - قوالb Notion متكاملة (Agency OS, Freelance CRM) وملفات Excel مدعومة بماكرو مالي.
  - ملفات تصميم وموارد 3D.
- **المميزات**: تصفية حسب القسم، البحث الفوري، فلترة (مجاني/مدفوع)، تفاصيل المنتج مع نافذة معاينة، سلة مشتريات منبثقة، دفع ومحاكاة شراء مع توليد تراخيص تحميل فورية واحتفال Confetti، وإمكانية نشر منتج جديد للبيع.

#### 2. 🎓 الأكاديمية (Hercules Academy)
- **دورات مدفوعة ومجانية ومسارات تخصص شاملة**:
  - مسار مهندس الذكاء الاصطناعي الكامل (AI Engineer Career Path).
  - مسار مصمم ومخرج الموشن جرافيكس التجاري (Motion Maestro).
  - مسار مطور الويب المتكامل (Full-Stack Elite Path).
- **مشغل دروس تفاعلي** مع تتبع الإتمام.
- **اختبارات تقييمية ومشاريع تطبيقية** مع تصحيح فوري وحساب النسبة المئوية.
- **شهادات إتمام معتمدة** برقم كود موثق `HERC-ACAD-2026-XXXX` وقارئ QR للتحقق السريع.

#### 3. 🤖 مركز واستوديو أدوات الذكاء الاصطناعي المدمج (In-App AI Workspace)
- **تشغيل واستخدام الأدوات داخل الموقع مباشرة**:
  - استوديو برمجة وتطوير (Coding Studio) لتوليد وفحص الأكواد لحظياً.
  - استوديو كتابة ومحادثة ذكية (Chat & Writing Studio).
  - استوديو تصميم وصور وفيديو سينمائي (Cinematic Visualizer).
  - استوديو تعليق صوتي ومحاكاة نبرات بشرية (Audio Studio).
- **صفر تكاليف على المالك (Zero-Cost Serverless)**:
  - المحرك التفاعلي يعمل على المتصفح مباشرة أو مفتاح API الشخصي للزائر (BYOK).

#### 4. 🚀 منصة إطلاق المشاريع (Hercules Launchpad)
- بيئة مخصصة للمطورين ورواد الأعمال وأصحاب المشاريع التقنية:
  - عرض المشاريع والتطبيقات (SaaS, AI Tools, Fintech, Mobile Apps).
  - التنافس على الترتيب اليومي مع تصويت مباشر Upvote.
  - جمع المستخدمين الأوائل عبر قوائم الانتظار الذكية (Waitlist).
  - سوق الشركاء والمؤسسين (Co-founders Board).

---

### 🛡️ تسجيل المستخدمين ولوحة التحكم الإدارية (Hercules Admin Center)
- **نظام المصادقة وتسجيل الدخول**:
  - نافذة تسجيل دخول وإنشاء حساب للزوار مع الحفظ اللحظي.
  - تظهر بيانات كل مستخدم جديد فوراً في لوحة الإدارة (`/admin`) في تبويب "المستخدمين المسجلين".
- **لوحة التحكم الشاملة**:
  - إحصائيات الإيرادات والمبيعات وتراخيص الشراء.
  - جداول أفقية منظمة للشهادات الصادرة والمبيعات.
  - إدارة صلاحيات المستخدمين وحذف/إضافة الحسابات.

---

### 🚀 التشغيل والنشر (Deployment on Vercel)

```bash
# تثبيت الاعتماديات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```
جاهز للنشر المباشر بنقرة واحدة على منصة Vercel.
